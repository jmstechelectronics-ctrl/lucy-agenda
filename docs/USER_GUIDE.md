# User guide

## Moving and resizing

Drag the header to move Lucy Agenda. Drag the corner grip at the lower right to resize it. The widget remembers both after you sign out or restart.

Use **TOP** to keep it above other windows. The bell switches calendar reminders on and off. The circular arrow refreshes tasks and appointments immediately.

## Views and calendars

Open the **⋯** menu for three views:

- **Show all** displays overdue, today, unscheduled and upcoming work.
- **Today only** keeps the list short for the current day.
- **Focus mode** displays overdue tasks and the nearest appointment.

The same menu contains **Visible calendars**. Untick a calendar to hide it from the widget; it remains unchanged in Google Calendar.

## TickTick tasks

Click the circle beside a task to complete it. Double-click the task card to open the task in TickTick. Right-click a task for rescheduling, priority, moving it to another list and deletion.

Use **+ → New TickTick task** to add a task. You can choose the TickTick list and optionally set a due date and time.

## Google Calendar events

Calendar entries have a coloured stripe matching their Google Calendar. Double-click an event to open it in Google Calendar. Right-click it to reschedule, edit its details, delete it or open it in Google Calendar.

Use **+ → New calendar event** to create an event. Lucy Agenda asks for a title, start time and duration, then saves it to your first editable Google calendar.

Changes to a recurring event apply to that occurrence. The event menu includes a Google Calendar link for changes to the whole series.

## Scrolling and refresh

Use a mouse wheel or two-finger touchpad gesture to scroll. The list has a small bounce at either end. At the top, pull down far enough to refresh; releasing early simply springs the list back. The final item remains above the resize grip.

Lucy Agenda refreshes both sources every five minutes. Unchanged data leaves the cards on screen, avoiding the previous refresh flash.
