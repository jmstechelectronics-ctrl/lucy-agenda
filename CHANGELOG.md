# Changelog

Lucy Agenda follows [semantic versioning](https://semver.org/). Version numbers describe the released source, not an online service.

## v1.0.1 — 27 October 2026

- Added complete installation, user and maintenance documentation.

## v1.0.0 — 27 October 2026

First public release.

- TickTick tasks and Google Calendar events in one desktop widget.
- Quick add, task actions, editable calendar events and calendar notifications.
- Today and Focus views, next-event countdown, smooth scrolling and pull-to-refresh.
- Position, size, opacity and always-on-top preferences persist between sessions.
- Starts automatically after sign-in through a user service.
